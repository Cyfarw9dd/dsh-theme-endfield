# 设计原则

本文回答**这个主题允许加什么、不允许加什么**，以及每一条**由谁来机械地拦住违规**。
不回答具体色值（→ [design-language.md](design-language.md)）、实现细节（→ [engineering-notes.md](engineering-notes.md)）与测试用法（→ [testing.md](testing.md)）。
下面三条来自仓库所有者的原始表述，是这套主题「为什么长这样」的总纲；改它们需要所有者本人拍板。

---

## 出发点

目标不只是「做一个好看的皮肤」，而是**能在自己的工作区里加入喜欢的元素和设计**——个性化本身就是产品目标，不是副产品。
但个性化必须付出两种代价，于是有三条不可协商的约束：

1. 只加入**必要**的元素和动效进行装饰；
2. 装饰**不影响核心工作区的输出**；
3. 动效**不影响性能**，从而不影响开发。

---

## 一、装饰是目的，但只做「必要的那一处」

**意图**：想加的是「喜欢的元素和设计」；不想做的是「把手上所有官方素材都堆上去」。

可检验的推论：

- **每加一件装饰都要能回答「它替代了什么、没有它会缺什么」**——答不出来就不加。
- **优先复用已有图层，而不是新增结构**：底纹用伪元素 + `background-image`（不新增 DOM、不改布局属性），品牌标识用 CSS 掩码而不是整张位图（5.7KB SVG 对 197KB 矢量原文件）。
- **大件默认关闭**：启动加载动画、雷霆大字默认 off，想要的人自己开。
- **素材取最省表达**：官方纹理原字节内嵌；徽标走矢量化掩码，而不是把模糊位图阈值化。

机械拦截：`test/texture.test.js`（底纹不得新增 DOM、不得改布局属性、必须静态）、`scripts/build-*.js --check`（产物不许手改漂移）。

---

## 二、装饰不进入核心工作区

**意图**：「不影响核心工作区的输出」= 不挡内容、不改阅读流、不参与工作区的判断与操作。

可检验的推论：

- 装饰节点一律 `pointer-events: none` + `aria-hidden`，**绝不拦截点击、选择、翻译**（水印连字形都由 CSS `content` 画，页面里根本没有文本节点可翻）。
- **层叠要么严格在正文之下，要么占用本来就空着的空间**：水印挂在会话列时取 `z-index:-1` 并给该列 `isolation:isolate`；新建会话页的标识放在标题**上方**的空位里。
- **纹理只锚定主内容列**，不铺满侧栏与外框——官方就是这么把底纹和内容结合的。
- **无装饰时功能必须完整**：总开关关掉即回到应用原生外观，设置页仍可读；没有任何功能只能在暗色或只能在有悬停能力的设备上用。

**已知边界（诚实登记，不是遗漏）**：新建会话页的标识插在应用的居中列里，会让编辑器整体下移约它一半高度——这是「贴在标题正上方」的必然代价，接受；它同时是**唯一**一个参与布局流的装饰。

机械拦截：`test/watermark-stacking.test.js`（像素级证明水印从不覆盖底部弹出菜单）、`test/hero-logo.test.js`（位置、`pointer-events`、只在新建会话页注入）。

---

## 三、动效必须付得起

**意图**：「动效不能影响性能，从而影响开发」= 动画的代价必须在预算内，且不能把开发体验变成等待。

可检验的推论：

- **只动合成器属性**：`transform` / `opacity` / 颜色。严禁动画 `width` / `padding` / `margin` / 位置这类会触发重排的属性。
- **悬停不得「创造几何」**：hover 才出现的伪元素或边框会让渲染器每帧重排（实测 8–16ms/s）；存在的做法是**预建几何 + 只切 opacity**，实测 0.00ms/s，**零就是标准**。
- **指针停住时不许继续烧 CPU**：代价只在移动时支付（parked pointer 是常见状态）。
- **尊重系统偏好**：`prefers-reduced-motion` 下位移/关键帧全部关闭，只留颜色反馈；另有 `prefers-reduced-transparency` 与 `prefers-contrast` 的降级。
- **装饰层自身不含动画**：底纹是静态的，不监听滚动，不做全窗模糊。

预算（数字定义在 `test/perf-motion.test.js`）：重排 ≤ 2ms/s（标准是 0）、主线程 ≤ 约 350ms/s（≈ 每帧 5.8ms）、帧间隔 p95/最差与 >32ms 帧比例、外加一条**静态守卫**扫描动效区里所有 `transition`/`@keyframes` 的属性白名单。

机械拦截：`test/perf-motion.test.js`、`test/motion-check.js`、`test/loader-performance.test.js`。

## 加东西前的三问（准入清单）

1. **没有它，工作区会缺什么？** 答不出来 → 不加。
2. **它会不会出现在工作区内容之上/之中，或者改掉布局流？** 会 → 重做，或者在上文「已知边界」里登记成有意识的代价。
3. **它的代价是多少？** 说得出数字（挂载一次 / 每帧 / 每次悬停）；超预算 → 重做。

## 谁在拦你

| 违反了 | 抓你的东西 |
| --- | --- |
| 装饰新增 DOM / 布局属性 / 常驻动画 | `test/texture.test.js` |
| 装饰盖住正文或弹层 | `test/watermark-stacking.test.js` |
| 动效超预算、动了非合成器属性 | `test/perf-motion.test.js`（静态守卫 + 预算） |
| 颜色自造、与依据不符 | `test/palette-contrast.test.js`；品牌素材见 `test/hero-logo.test.js`（与源文件比对） |
| 生成物手改漂移 | `scripts/build-*.js --check`（已接入 `npm run check` / `npm test`） |
| 素材来源不明 | `scripts/build-*.js` 头注 + README「素材归属」双重登记（人工） |
